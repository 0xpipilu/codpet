# Asset Policy / 素材政策

Codpet is a personal curated collection. It does not currently accept third-party pet submissions or promise that every historical asset has the same provenance.

## Public asset categories

### Pet packages

Each directory under `pets/` may contain a pet package, preview image, animation, and metadata. Before treating a pet as reusable or redistributable, its source and permission status should be checked individually.

The repository does not make a blanket claim that every character or reference image is an original work by the maintainer. If an asset's redistribution or derivative-work permission cannot be established, it should not be used for a new public release and should be removed or replaced after review.

### Website branding and UI assets

`assets/brand/` contains the website's logo, favicon, and social preview assets. `assets/icons/` contains the small UI icons used by the public gallery. These are maintained as project assets; source provenance should be recorded when an asset is replaced or imported from elsewhere.

### Local-only source material

The following paths are excluded from the public repository by `.gitignore`:

- `assets/source/`
- `apps/_local-assets/`
- `apps/_experiments/`

They may contain design exports, fonts, app icons, experiments, and references whose redistribution rights have not been verified. Their presence in the local workspace is not a license to redistribute them.

## Rules for future additions

For a new public pet or visual asset, keep a short provenance note covering at least one of:

- created by the maintainer;
- used under an identified open license;
- used with permission from the rights holder;
- supplied by the user and confirmed for the requested use.

Do not present a third-party character as an original Codpet creation. Do not upload copyrighted reference material merely because it was found online. When the status is unclear, keep the material local until it is replaced or permission is obtained.

This document describes the project's intended handling practice and is not legal advice.
